Классификация фишинговых писем
В этом проекте я анализирую признаки писем и сравниваю модели машинного обучения для обнаружения фишинга. Основная задача — находить больше фишинговых писем и оценить, сколько обычных писем при этом ошибочно попадёт под подозрение.
Данные
Датасет содержит 524 846 записей, 8 числовых признаков и целевую переменную label: 1 — фишинг, 0 — обычное письмо. Фишинговых писем около 1,32%, поэтому одной accuracy для оценки недостаточно.

Признаки описывают количество слов, уникальных слов, стоп-слов, ссылок, уникальных доменов, email-адресов, орфографических ошибок и срочных ключевых слов.
Что сделано
- Исследованы распределения признаков и корреляции.
- Данные разделены на train, validation и test. Одинаковые наборы исходных признаков не пересекаются между выборками.
- Добавлены относительные признаки, например количество ссылок на слово.
- Сравниваются Logistic Regression, Random Forest, ExtraTrees и HistGradientBoosting с разными настройками.
- Для дисбаланса используются веса классов; масштабирование обучается только на train.
- Модель выбирается по минимальной доле ложных тревог при recall не ниже 80% на validation. Пороги также подбираются только на validation.
Результаты
В проверенном запуске по выбранному правилу лучшим оказался HistGradientBoosting.
Режим	Recall	Precision	Ложные тревоги среди обычных писем
recall_80	81,6%	4,2%	24,5%
FPR_5pct	49,9%	11,3%	5,2%


Высокая полнота достигается ценой большого числа ложных тревог. Названия режимов обозначают цели на validation, а не гарантии для новых данных.

Test уже использовался в предыдущих экспериментах, поэтому это повторное сравнение. Для независимого подтверждения нужны новые письма.
Запуск
Проверено на Python 3.12. Скачайте репозиторий и откройте терминал в папке проекта:
python -m pip install -r requirements.txt
python -m jupyterlab
Откройте email_phishing_classifier.ipynb и выполните Restart Kernel and Run All Cells. Файл email_phishing_data.csv должен находиться рядом с ноутбуком.
В качестве альтернативы можно открыть через Google Collab: 
1. Скачать и распаковать .zip.
2. Открыть Google Colab.
3. Выбрать Загрузить блокнот и указать email_phishing_classifier.ipynb.
4. Подключиться, затем слева открыть значок папки и загрузить email_phishing_data.csv.
5. Выбрать Среда выполнения -> Перезапустить и выполнить весь код.


Для смены режима измените переменную MODE: доступны recall_60, recall_80, recall_90 и FPR_5pct.
