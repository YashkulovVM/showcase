Этот репозиторий представляет из себя витрину моих пректов.

В каждой директории находится один отдельный проект или связанные задачи.
Для каждой из них внутри директории есть свой README, который подскажет, как их запустить.

| Проект | Описание |
| `C++` | Решение задач на C++: списки, разные задачи с деревьями и тд |
| `Everspace 2 Trade Database` | Проект по SQL, база всех цен у всех торговцев в игре Everspace 2 |
