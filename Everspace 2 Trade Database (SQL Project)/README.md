Everspace 2 Trade Database

База торговых цен Everspace 2 на PostgreSQL. Проект объединяет системы, регионы, торговцев и товары и позволяет сравнивать цены с помощью SQL.

В наборе данных — 408 записей цен для шести систем: CETO, UNION, DRAKE, ZHARKOV, KHAIT NEBULA и KHIONE. Это снимок данных из источника (гугл дока, который сделал участник комьюнити), а не автоматически обновляемые цены из игры.

| Файл | Назначение |
| --- | --- |
| `data/prices_import.csv` | Исходные данные для импорта |
| `sql/creation.sql` | Создание основных таблиц и промежуточной таблицы `raw_prices` |
| `sql/insertion.sql` | Заполнение основных таблиц из промежуточной `raw_prices` |
| `sql/setup.sql` | Последовательный запуск создания таблиц и импорта в одной транзакции |

| Таблица | Содержимое |
| --- | --- |
| `systems` | Звёздные системы |
| `regions` | Регионы внутри систем |
| `traders` | Торговцы и их расположение |
| `commodities` | Товары |
| `prices` | Цена товара у конкретного торговца |
| `raw_prices` | Промежуточные данные из CSV перед заполнением основных таблиц |

Запуск
Импорт пересоздаёт таблицы проекта. creation.sql удаляет таблицы raw_prices, prices, traders, commodities, regions и systems, если они существуют. Запускайте его в отдельной базе проекта.
1. Скачайте проект
Клонируйте репозиторий или скачайте его через Download ZIP и распакуйте архив.

2. Создайте базу данных
Если отдельной базы ещё нет, подключитесь к PostgreSQL через DBeaver, pgAdmin или другой SQL-клиент и выполните отдельной командой, вне транзакции:
```
CREATE DATABASE everspace_trade;
```
3. Запустите импорт

Откройте терминал в корневой папке репозитория, перейдите в sql и выполните:
```
cd sql
psql -h localhost -p 5432 -U postgres -d everspace_trade -f setup.sql
```
Можно также запустить sql/creation.sql, затем импортировать в raw_prices содержимое data/prices_import, используя внутренние возможности программы (например, DBeaver), а затем запустить sql/insertion.sql.

4. Проверка загрузки
Подключитесь к базе проекта в SQL-клиенте и выполните:
```
SELECT COUNT(*) AS price_count
FROM prices;
```
